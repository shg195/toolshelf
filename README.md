# toolshelf

Small browser-only tools. Nothing you load ever leaves the page.

**https://shg195.github.io/toolshelf/**

ブラウザの中だけで動く、小さな道具を置いています。無料で、登録もいりません。

## Why browser-only

There is no server. Files you load are processed in your browser and stay there —
not because of a privacy policy, but because there is nowhere to send them.

Tools that use an LLM take **your own API key** (BYOK). Keys are never stored here.

## Contents

- **`kit/`** — A starter kit for making AI keep your context across sessions.
  Two layers: a **chat version** (paste into ChatGPT / Claude / Gemini — free) and a
  **Claude Code version** (CLAUDE.md template + 3 skills).
  **Intentionally incomplete** — the blanks are filled in by *your* AI, reading *your* project.

More tools are added as they are built. No roadmap dates.
