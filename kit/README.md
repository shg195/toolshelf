# Claude Code スターターキット（不完全版）

私が実際に毎日使っている Claude Code の設定一式を、**あなた用に完成させられる形**で置いてあります。

> ### 🔸Claude Code を使っていない方は [チャット版キット](チャット版キット.md) へ
> ChatGPT・Claude・Gemini の**チャットにそのまま貼って使える版**です。無料で使えます。
> こちら（Claude Code版）は、コマンドラインで本格的に使う人向けです。

## これは何か

Claude Code を使い始めると、たいてい同じ壁に当たります。

- 毎回同じ前提を説明し直している
- セッションを閉じたら、何をどこまでやったか分からなくなる
- 頼んでいないファイルまで書き換えられる
- 「できました」と言われたが、実は動いていない

この4つは**設定で潰せます**。このキットは、その設定の型です。中身は3つだけ。

| 中身 | 何をするか |
|---|---|
| `CLAUDE.md` | 毎セッション自動で読まれる指示書。「勝手にやらない」「報告の形式」を固定する |
| メモリ | 会話を跨いで残る記憶。次のセッションが前回の続きから始まる |
| skill 3本 | `/kit-setup`（初期設定）・`/kit-standup`（開始時に現在地を出す）・`/kit-handoff`（終わる前に引き継ぐ） |

## ⚠️ わざと不完全にしてあります

`CLAUDE.md` の中には `<...>` の空欄が残っています。**埋めるのはあなたのAIの仕事です。**

理由：私の環境向けに完成した設定をそのまま渡しても、あなたには合いません。私は Windows で個人開発をしている学生で、あなたとは使う言語も、触るファイルも、怖い操作も違います。**設定の価値は「その人に合っていること」にあって、中身の立派さではない**からです。

なので、雛形と「完成させる手順」を渡します。

## 入れ方（5分）

**1.** このフォルダの中身を、あなたのプロジェクトのフォルダ直下にコピーします（GitHubの「Code → Download ZIP」で丸ごと落とせます）。

```
あなたのプロジェクト/
├── CLAUDE.md            ← 空欄つきの雛形
├── メモリの書き方.md      ← メモリの書式（/kit-setup が参照します）
├── LICENSE              ← MIT
└── .claude/
    └── skills/
        ├── kit-setup/SKILL.md
        ├── kit-standup/SKILL.md
        └── kit-handoff/SKILL.md
```

**`.claude` は先頭がドットの隠しフォルダです。**コピー漏れが起きやすいので、貼った後に存在を確認してください。

**2.** そのフォルダで Claude Code を起動します。

```
claude
```

**3.** これを打ちます。

```
/kit-setup
```

**4.** あとは聞かれたことに答えるだけです。AIがあなたのプロジェクトを読んで、空欄を埋め、メモリの置き場を作ります。5分ほどで終わります。

`/kit-setup` が使えない場合は、代わりにこう頼んでください（同じことが起きます）。

```
CLAUDE.md の <...> の空欄を、このプロジェクトを実際に読んで埋めてください。
埋める前に、あなたが何をどう埋めるつもりかを一覧で見せてください。
私が確認したら反映してください。
```

## 2日目からの使い方

- セッションを開いたら **`/kit-standup`** — 前回どこで止まったか、次の一手は何かが1枚で出ます
- 終わる前に **`/kit-handoff`** — 次のセッションが迷わず再開できる状態にしてから閉じます

この2つを挟むだけで、「毎回説明し直す」が消えます。

## うまくいかないとき

- **`/kit-setup` が反応しない** … `.claude/skills/kit-setup/SKILL.md` の位置を確認してください。**フォルダ名がそのままskill名になります。**
- **skill名の頭に `kit-` が付いている理由** … あなたが既に持っているskillと名前がぶつからないようにするためです。もし同じ名前のものが既にあると、`/フォルダ名:skill名` の形で表示されます（両方使えますが、呼び名が変わって分かりにくいので、最初から衝突しない名前にしてあります）。`/` を打つと候補が出るので、迷ったらそこから選んでください。
- **CLAUDE.md が読まれていない気がする** … `/memory` で読み込まれている内容を確認できます。
- **指示が守られない** … CLAUDE.md が長すぎる可能性があります。長くなるほど追従は落ちます。ただし**「何行までなら大丈夫」を断定できる根拠は私は持っていない**ので、行数の目安は書きません。代わりの判断基準はこれです——**同じことを2回書きたくなったら、それが skill に出す合図です。**長い手順は skill に退避させてください（それが skill の役割です）。
