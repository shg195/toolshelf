# AI作業場スターターキット（チャット版・不完全版）

ChatGPT・Claude・Gemini のどれを使っていても、**無料のまま**、AIを「毎回初対面の物知り」から「あなたの事情を知っている働き手」に変えられます。

このページ1枚で完結します。**あなたが使っているAIの節だけ読んでください。**

---

## これは何か

AIを使っていると、たいてい同じところで詰まります。

- 毎回、同じ前提を説明し直している
- チャットを閉じたら、話した内容が消える
- 頼んでいないことまで書き足される
- 「できました」と言われたが、よく見ると違う

この4つは**設定で減らせます**。中身は3枚だけです。

| 枚 | 何をするか | 置き場所 |
|---|---|---|
| ① ルール | AIの答え方と作法を固定する | 指示欄（1回貼れば以後ずっと効く） |
| ② 記憶シート | あなたの状況をAIに持たせる | ファイルとして置く |
| ③ 手順書 | よく頼む作業を型にする | 使うときに貼る |

## ⚠️ わざと不完全にしてあります

①の中には `<...>` の空欄が残っています。**埋めるのはあなたのAIの仕事です。**

私の設定をそのまま渡しても、あなたには合いません。私は学生で、あなたとは頼む内容も、困っていることも違います。**設定の価値は「その人に合っていること」にあって、中身の立派さではない**からです。だから雛形と、完成させる手順を渡します。

# 手順1｜あなたのAIの節を読む（貼り先が違うだけです）

## ChatGPTを使っている場合

**器＝プロジェクト機能**（無料プランで使えます／2026-07-25 確認）

1. 左のメニューからプロジェクトを新しく作る
2. そのプロジェクトの**指示欄**に、下の**①ルール**を貼る
3. **②記憶シート**をテキストファイルにして、プロジェクトにアップロードする
4. **③手順書**は、使うときにチャットへ貼る
5. 以後、その話題のチャットは**このプロジェクトの中で始める**

> **カスタムGPTについて**：カスタムGPTの**作成には有料プランが必要**です（2026-07-25 確認）。無料でやるなら、上のプロジェクト機能で同じことができます。

## Claudeを使っている場合

**器＝プロジェクト機能**（無料プランで使えます。**作れる数に上限があります**／2026-07-25 確認）

1. プロジェクトを新しく作る
2. そのプロジェクトの**カスタム指示**に、下の**①ルール**を貼る
3. **②記憶シート**を、プロジェクトのナレッジ（資料）として添付する
4. **③手順書**は、使うときにチャットへ貼る
5. 以後、その話題のチャットは**このプロジェクトの中で始める**

> 無料プランはプロジェクトを作れる数が限られています（確認時点で5件）。**一番よくやる作業から1つ**作るのがおすすめです。

## Geminiを使っている場合

**器＝Gem**（無料プランで作れます／2026-07-25 確認）

1. Gemを新しく作る
2. **指示欄**に、下の**①ルール**を貼る
3. **②記憶シート**を、Gemのナレッジファイルとして添付する
4. **③手順書**は、使うときにチャットへ貼る
5. 以後、その話題はこのGemに話しかける

> 添付できるファイル数の上限は**未確認**です（公式に現行の数値が見つかりませんでした）。まず1ファイルから始めてください。

# 手順2｜完成させる（AIにやらせます）

新しいチャットを開いて、**下の指示文と①をまとめて貼ってください。**

```
これから「AIの作業ルール」の雛形を渡します。<...> の部分が空欄です。
私に質問して、空欄を埋めた完成版を作ってください。

・質問は一度に3つまで。私にしか答えられないことだけ聞いてください（調べれば分かることは聞かない）
・埋める前に、何をどう埋めるつもりかを一覧で見せてください
・私が確認してから、完成版の全文を出してください
・答えに困った欄は、埋めずに <...> のまま残してください

--- ここから雛形 ---
（①ルールをここに貼る）
--- ここまで ---
```

出てきた完成版を、手順1の指示欄に貼れば終わりです。

# ① ルール（貼る中身・空欄つき）

```
# 私のこと

- 立場：<学生 / 会社員 / 個人事業 など>
- よく頼むこと：<レポート / 資料作り / 調べもの / プログラム など>
- 詳しくない分野：<ここに書くと、その分野は噛み砕いて説明してもらえます>

# 答え方

- 結論を先に言う
- 前置きと締めの挨拶を入れない
- 分からないことは「分からない」と言う。それらしく埋めない
- 事実と、あなたの意見を分けて書く
- 言葉づかい：<ですます / くだけた口調>

# やってほしくないこと

- 聞いていないことまで書き足す
- 断定できないことを断定する
- 私が渡した文章を、頼んでいないのに書き換える
- <一度やられて困ったことを書く。この行が一番効きます>

# 進め方

- 一度に一つずつ進める
- 長い作業は、途中で「この方向で合っているか」を確認する
- <あなたのやり方を足す>
```

**一番効くのは最後から2つ目の行です。** 一般論のルールより、**あなたが実際に困った一件**の方が強く効きます。

# ② 記憶シート（貼る中身）

```
# 覚えておいてほしいこと（更新日：____）

## 今やっていること
- 目的：<何を、いつまでに>
- 現在地：<今どこまで進んだか>

## 決めたことと、その理由
- <選んだ判断＋なぜそうしたか>

## 私の条件
- <使っている道具・制約・締切・避けたいこと>
```

**書き方の注意が2つあります。**

- **「来週」と書かない。実際の日付で書く。** 相対的な日付は1週間で意味が変わって、あとで自分が読めなくなります
- **理由を書く。** 半年後に読み返したとき、何を決めたかより「なぜそう決めたか」の方が役に立ちます

節目（何かを決めた・区切りがついた・方針を変えた）で更新してください。毎回更新する必要はありません。

## 正直に書いておくこと

- **これは魔法ではありません。** AIの賢さが上がるわけではなく、AIが見ている材料が増えるだけです。ただ、答えの質は賢さより材料で決まる場面の方が多い、というのが私の実感です
- **3製品とも、作った設定を他人にそのまま渡すことはできません**（2026-07-25時点。ChatGPTのカスタムGPTは作成が有料、Claudeのプロジェクト共有は法人向けプラン限定）。だからこのキットは「器」ではなく「貼る中身」を配る形にしてあります
- **①を長くしすぎないでください。** 長くなるほど、書いたことが守られにくくなります（私の環境ではそうでした）。増やしたくなったら、③の手順書側に逃がしてください

## うまくいかないとき

- **ルールが守られていない気がする** … ①が長すぎる可能性があります。まず「やってほしくないこと」を3行に絞ってみてください
- **記憶シートを見てくれない** … そのチャットを、作ったプロジェクト／Gemの**中で**始めているか確認してください。外で始めると設定は効きません
- **それでも駄目なとき** … 動かなかった状況を教えてもらえれば直します
